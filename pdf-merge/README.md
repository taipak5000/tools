# PDF結合

複数のPDFを1つにまとめて、まとめて印刷するための静的サイトです。処理はすべてブラウザの中で完結し、PDFはサーバーへ送信されません。

## できること

- PDFを複数ドロップして1つに結合（ドラッグまたは↑↓ボタンで順番を変更、名前順の並べ替えも可）
- ファイルごとのページ範囲指定（例: `1-3,5,8-`）
- 全ページをA4に揃える（縦横の向きは元のまま、用紙に収まるよう拡大・縮小）
- 両面印刷用に、奇数ページのファイルの後ろへ白紙を1枚追加
- 結合後のPDFをダウンロード、またはブラウザのPDFビューアで開いてそのまま印刷

## GitHub Pagesで公開する

1. このフォルダの中身をリポジトリの直下に置いてpushする（`index.html` が最上位に来る形）。
2. GitHubのリポジトリで **Settings → Pages** を開く。
3. **Build and deployment** の Source を `Deploy from a branch` にし、Branch は `main`、フォルダは `/ (root)` を選んで保存する。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける。

ビルド作業は要りません。

## 手元で動かす

`index.html` をブラウザで開くだけで動きます。ローカルサーバーを使う場合は、このフォルダで次を実行します。

```
python3 -m http.server 8000
```

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面 |
| `style.css` | 見た目（ダークモード対応） |
| `app.js` | 画面の動き（追加・並べ替え・結合ボタン） |
| `merge.js` | 結合ロジック。画面に依存しないので単体でテストできる |
| `vendor/pdf-lib.min.js` | PDF操作ライブラリ pdf-lib 1.17.1（MIT License、`vendor/pdf-lib.LICENSE.md`） |

pdf-libをCDNではなくリポジトリに同梱しているので、外部サービスの停止やバージョン変更の影響を受けません。

## 制限

- パスワード付きのPDFは読み込めません（先にパスワードを外してください）。
- 読み込んだファイルはメモリ上に保持します。合計で数百MBを超えるPDFを扱うと、端末によっては重くなります。
- 「A4に揃える」を使うと、元のPDFの注釈やリンクなどはページの絵として取り込まれ、操作できなくなります。使わない場合は元のページをそのままコピーします。
