# お小遣い帳

複数の財布（財布の中身・貯金箱・コインケースなど）を登録して、入金・出金・振替を記録するWebアプリです。
ホーム画面に追加するとアプリのように使えます。

## 財布一覧

- 財布を好きな名前でいくつでも登録できます。
- 財布ごとに色を設定できます（14色のプリセット、または好きな色を指定）。
- 財布ごとに「合計に含める」を切り替えられます。含めない財布は一覧に「合計外」と表示され、上部の合計残高から除外されます。
- 一覧の上部に合計残高と、今月の入金合計・出金合計を表示します。
- 財布を追加するときに「今の残高」を入れると、その金額が初期残高として記録されます。

## 財布の編集・並び替え

- 一覧右上の「編集」から開きます。
- 右端の ≡ を上下にドラッグすると並び替えできます。
- 左端の赤いボタンで財布を削除します。その財布の記録も一緒に消えます。
- 財布の名前をタップすると、名前・色・「合計に含める」を変更できます。

## 財布内の記録

財布を開くと、画面下部に「残高」「入金」「出金」のボタンが並びます。

- 入金・出金: 金額を入れて記録します。メモは任意です。日時は現在時刻が自動で入り、あとから変更できます。
- 残高: 実際に数えた金額を入れると、記録上の残高との差額が「残高の調整」として記録されます。
- 記録は日付ごとにまとめて表示されます。記録をタップすると、金額・メモ・日時の変更や削除ができます。
- 財布の上部には残高と、今月の入金合計・出金合計を表示します。

## カテゴリ

- 「食費」「ゲーム」など、お金の使いみちごとにカテゴリを作れます。名前と色は自由に設定できます。
- 入金・出金を記録するときにカテゴリを選べます（任意）。振替と残高の調整にはカテゴリを付けません。
- 設定画面の「カテゴリの編集」から追加・名前変更・並び替え・削除ができます。削除しても記録は消えず「未分類」になります。
- 最初から「食費」「おやつ・ジュース」「ゲーム」「本・マンガ」「交通費」「服・小物」「お小遣い」「プレゼント」「その他」が入っています。

## カテゴリ別の月間集計

「集計」タブで使います。

- ‹ › で月を切り替えます。真ん中の年月をタップすると今月に戻ります。
- 「出金」「入金」を切り替えて、その月の合計と、カテゴリごとの金額・割合・件数を表示します。
- カテゴリをタップすると、その月・そのカテゴリの記録一覧（検索画面）が開きます。
- 振替と残高の調整は集計に含みません。合計外の財布の記録は含みます。

## 記録の検索・期間絞り込み

財布一覧の左上の虫めがねから開きます。

- メモとカテゴリ名で文字検索できます。入力するたびに結果が更新されます。
- 「今月」「先月」「3か月」「今年」「全期間」のボタンで期間を素早く指定できます。開始日・終了日を直接入れることもできます。
- 財布・カテゴリ（未分類も選べます）・種類（入金・出金・振替・残高の調整）で絞り込めます。
- 結果の上に件数と入金合計・出金合計を表示します。記録をタップすると編集・削除できます。
- 右上の「クリア」で条件をすべて外します。

## 振替

- 移動元と移動先の財布を選び、金額を入れると、両方の財布に「振替」として一度に記録されます。
- 移動元と移動先は中央のボタンで入れ替えられます。
- どちらか片方の振替記録を編集・削除すると、もう片方も一緒に変わります。
- 振替は入金・出金の集計には含まれません。

## 残高推移グラフ

- 月末時点の残高を折れ線グラフで表示します。
- 期間は 6か月・12か月・全期間 から選べます。
- 「合計」と「財布ごと」を切り替えられます。財布ごとの表示では、各財布の色で線が引かれます。
- グラフをなぞると、その月の残高が上部に表示されます。
- グラフの下に、月ごとの合計残高・入金合計・出金合計・前月との差を一覧で表示します。

## バックアップ

設定画面から使います。

- 書き出す: 財布と記録をJSONファイルとして保存します。
- 読み込む: 保存したJSONファイルを読み込みます。今のデータはすべて置き換わります。
- すべてのデータを削除: 財布と記録をすべて消します。

## データの保存場所

記録はブラウザの localStorage（端末内）にだけ保存され、サーバーには送りません。
機種変更やブラウザのデータ削除に備えて、ときどきバックアップを書き出しておいてください。

## ホーム画面に追加

- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）: メニュー → 「ホーム画面に追加」または「アプリをインストール」

追加後はオフラインでも起動します。
