# お小遣い帳

複数の財布（財布の中身・貯金箱・コインケースなど）を登録して、入金・出金・振替を記録するWebアプリです。
ホーム画面に追加するとアプリのように使えます（PWA対応）。

## 公開のしかた（GitHub Pages）

このフォルダの中身をリポジトリのルート（または `docs/`）に置き、Settings → Pages で公開元を指定するだけで動きます。
すべて相対パス（`./`）で書いてあるので、`https://ユーザー名.github.io/リポジトリ名/` のようなサブディレクトリでも問題ありません。

```
index.html
manifest.webmanifest
sw.js
css/style.css
js/app.js
icons/
```

## ホーム画面に追加

- iPhone（Safari）: 共有ボタン → 「ホーム画面に追加」
- Android（Chrome）: メニュー → 「ホーム画面に追加」または「アプリをインストール」

## データの保存場所

記録はブラウザの localStorage（端末内）にだけ保存されます。サーバーには送りません。
機種変更に備えて、設定画面の「バックアップを書き出す」でJSONを保存しておいてください。

## 更新について

Service Worker は stale-while-revalidate 方式です。
サイトを開くと表示はキャッシュから即座に行い、裏側で最新版を取得してキャッシュを入れ替えます。
2回目に開いたときに更新が反映されるので、`sw.js` の `CACHE_NAME` を毎回上げる必要はありません。
